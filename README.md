# Дело Ксюши №404

Дружеский интерактивный сайт с подколами, мини-играми и совершенно официальным расследованием безделья Ксюши.

Готовая статическая версия лежит в корне репозитория, а исходники React/Vite — в папке `app`.

## Запуск локально

```bash
npm install
npm run dev
```

## Публикация

Каждое обновление ветки `main` автоматически собирается и публикуется через GitHub Pages.
